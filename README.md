# 🔒 Secure Proxy Browser

Android browser with auto-proxy configuration. Fetches live proxy credentials from server - zero manual setup.

## 📦 Source Code

Download `Secure-Proxy-Browser-(src).zip` and extract.

## 🛠️ Tech Stack

- Java, Android SDK
- WebView + NetCipher
- REST API for proxy fetching
